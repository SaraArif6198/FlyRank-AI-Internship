# Week 3 — Decide Once: My Identity Kit

I chose a system that feels calm, capable, and field-tested. The portfolio is about production software that replaces paper, so the identity uses editorial structure and one sharp signal instead of decorative noise.

**Type:** Space Grotesk for headings; Inter for body.  
**Palette:** forest `#355E4A`, ink `#171A16`, paper `#F4F1E8`, signal lime `#C7F36B`.  
**Mark:** a simple `SA` monogram—the S reads as a path through a process, and the A as the structure underneath it.
