# Operator checklist

1. Open the Claude Project containing `CLAUDE_PROJECT_INSTRUCTIONS.md`.
2. Start a new chat so no earlier project facts leak into the test.
3. Paste a completed `INPUT_TEMPLATE.md`.
4. Start the timer immediately before sending.
5. Stop when Claude returns `STATUS`.
6. Confirm all five headings exist: fact ledger, draft, critique, revision/change log, final verification.
7. Human-review every item under `HUMAN CHECK` and every number, proper name, quote, permission, and status label.
8. If status is `NEEDS HUMAN FACT`, answer the question with a source or remove the sentence; never tell Claude to “make a reasonable assumption.”
9. Save the complete run, elapsed time, human-review time, and final disposition.

## Brand/voice card

Direct, plain, specific, honest. Short sentences. Numbers over adjectives. Keep one honest wrinkle.

Banned: passionate, results-driven, dynamic, leveraged, spearheaded, cutting-edge.
